Bachelor Thesis - Project Application

Web application for ticketing and merchandise

The application’s requirements can be described as follows:

The system includes multiple user roles (admin, employee, customer) and utilizes advanced security measures such as JWT.

  • Registration and Login: Three types of users: admin, employee, and customer. Upon registration, the user is assigned the customer role and predefined credit.
  • Security: Information is encrypted, and access is restricted through JWT tokens stored in local storage.
  • Event Information: Each event provides details about the venue, description, date, participating artists, and ticket options (VIP or Standard).
  • Product Details: Clothing items such as T-shirts, hoodies, and socks are available with size options, including XS to XL for shirts and specific sizes for socks.
  • Product Sorting: Clothes can be sorted by color, artist, and event location, while events can be sorted by location and type.
  • Product Evaluation: Users can add reviews for products, which include an average rating based on user feedback.
  • Shopping Cart Management: Management of items in the cart, with feedback for errors such as insufficient credit or unsuccessful cart additions.
  • Address Management: Users can add multiple addresses, which are linked together for redundancy prevention and efficiency.

This application is designed to handle large volumes of data efficiently and provides robust features for user interaction and product management.
